# CSMS
This is a Cloth Store Management System. Its a well-structured Python application made with Tkinter alongside SQLite, Developed as my 3rd semester Python and DBMS academic project.

This is full-featured desktop application built with Python Turtle (animated splash screen),
Tkinter (main GUI), and SQLite (RDBMS backend).

The database schema creation and updation code is within the main pythhon code so there is no need to separately make changes in sqlite

you can run this code even without SQLite if you want to observe its functionality
